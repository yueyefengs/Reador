# Reador

AI 辅助阅读与学习助手：围绕一本书，将章节总结、概念图谱和 AI 问答连接到主动回忆、测验反馈与 FSRS 间隔复习。

## 当前状态

项目已建立开发约定与产品、技术方案，并提供可直接打开的本地交互原型。尚未接入真实 AI、书籍解析、数据库或 FSRS 调度。

参考 [Learny](https://github.com/augusto-dmh/learny) 的结构化原文、可追溯引用与 FSRS，以及 [Tutor](https://github.com/rsml/tutor) 的学习档案、选段讲解与反馈驱动教学。Reador 保留原书，根据学习表现调整辅助讲解和练习。

## 打开产品原型

无需安装依赖，直接用浏览器打开项目根目录的文件：

- [dashboard.html](dashboard.html)：今日学习、书库、Mermaid 概念图工作台、按书籍查看示例复习计划、Agent 配置和三种外观。
- [reader.html](reader.html)：章节阅读、总结、示例问答、引导教学和回忆检测。

Dashboard 的“继续阅读”进入阅读工作台；工作台左上角的 `reador.` 返回 Dashboard。在 macOS 项目目录中也可以执行：

```bash
open dashboard.html
```

体验新流程：**我的书库 → 生成示例概念图 → 点击图中概念 → 查看原文依据**。可切换全书/章节、横向/纵向布局，编辑并校验 Mermaid 源码，再导出 `.mmd`、带来源的 Markdown 或 SVG。

书库采用一书一卡的封面网格，卡片展示书名、状态、阅读与图谱入口；末尾的添加卡片可选择新书。尚未解析的文件使用标注为“文字封面”的占位设计，不展示虚构作者或阅读进度。

复习计划支持选择「全部书籍」或单本书，按书展示知识点、章节来源、待回忆与本轮完成数量。书库卡片的「查看复习计划」直接进入该书；「开始本书复习」只选择当前书的待回忆内容。尚未解析的书籍显示空状态，不套用示例题目。完成自评后，书库与复习页同步更新本轮数量；刷新后重置，尚不生成真实到期时间。

在侧栏进入 **系统设置 → Agent 配置**（也可直接打开 `dashboard.html#settings`），可选择 OpenAI、Anthropic / Claude、智谱 / GLM、DeepSeek 官方预设，或第三方 / 自建网关、自定义厂商。提供 Responses、Messages、Chat Completions 三种协议的配置界面、完整请求地址预览，以及模型 ID、超时、重试、最大输出 tokens 和可选 Temperature。支持多组配置的新增、编辑、删除及默认 Agent 选择。

配置仅保留在本页内存，刷新或离开页面后重置，不改变现有示例问答与图谱行为。API Key 字段仅演示输入与显隐，保存、取消或离开设置视图时清空，不进入配置记录、浏览器存储或网络请求。「检查配置格式」只校验输入，不代表连接成功；真实密钥保管和模型调用需要后续服务端实现。

请保留 HTML 旁的整个 `assets/` 目录。Mermaid 12.1.0 已包含在项目中，渲染和导出可离线运行；不是依靠远程 CDN 的截图。

原型使用原创示例材料和预设反馈。选择自己的 PDF / EPUB 可加入待解析列表，但不读取、上传或解析正文，不会套用示例图。列表、源码编辑和学习记录仅保留在各页面的内存中，刷新或跨页跳转后重置；尚无真实 Agent、AI 评分或复习排期。

## 书库与概念图

目标流程是 **上传一本书 → 解析原文 → Agent 提取概念与有依据的关系 → Mermaid 总览和章节子图 → 从图谱回到阅读与检测**。

项目已引入用户指定仓库中的 [mermaid-visualizer skill](skills/mermaid-visualizer/SKILL.md)，固定上游提交并保留 MIT 许可证。该 skill 提供分析、布局和语法规则；真实生成仍需后续的解析、模型调用、引用校验及持久化。详见 [Agent 设计](docs/book-concept-agent.md) 和 [上游来源](skills/mermaid-visualizer/SOURCE.md)。

## 学习闭环

```text
一本书
  ↓
章节阅读 → 总结 / 概念图谱 / AI 问答
  ↓
主动回忆 / AI 出题
  ↓
评分与反馈
  ├─ 本轮达到标准 → 确认评级 → FSRS 安排复习
  └─ 未达到标准   → 针对性讲解 → 再次测试
                                       ↓
                              保留表现与薄弱项

到期复习 → 再次回忆与检测 → 更新下次复习时间
```

所有 AI 解释尽可能回到原文核对。答题得分与记忆评级分开记录；讲解后的即时答对不能直接代表长期掌握。

## 开发顺序

1. 以有文本层的 PDF / 无 DRM 的 EPUB 为目标入口，搭建单体应用，完成真实导入、原文定位与持久化；逐个接入解析器。
2. 优先打通一本书的概念抽取 Agent、来源校验、Mermaid 编译及版本保存，使现有书库原型连接真实数据。
3. 完成章节阅读、带来源的总结、问答与教学，再连接主动回忆、出题、评分、讲解与再次测试。
4. 接入 FSRS 和到期复习队列，验证完整闭环。

建议采用 TypeScript / Next.js、PostgreSQL 与现成 FSRS 库，具体选型待进入实现阶段确认。依赖安装、环境变量和运行命令将在实际搭建应用后补充。
